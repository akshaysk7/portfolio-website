Premier League Match Predictor

Feature engineering stage

A supervised classification model that predicts match outcomes — home win, draw, or away win — from historical match data.

  1. Data
  2. Feature engineering
  3. Modelling
  4. Evaluation

The interesting constraint

Football is genuinely high-variance. Bookmakers, with far more data and money than I have, land around 55% accuracy. So this project isn’t really about hitting a big number — it’s about extracting real signal from noise and being honest about evaluation.

A deliberate choice

I excluded bookmaker odds from the feature set. Including them would mean decoding someone else’s prediction and calling it mine. The point is to build the prediction, not to launder one.

College Document Q&A (RAG)

Shipped · under review

A retrieval-augmented generation system that answers questions about college rules and circulars — and cites the source document for every answer it gives.

question retrieve from circulars covered? yesanswer + cited source norefuse · log to gap report

It knows when to stop

If the documents don’t cover a question, it refuses to answer rather than inventing something plausible. For an official-rules system, a confident wrong answer is worse than no answer.

The unanswered questions are the product

Every query it can’t answer gets logged into a documentation-gap report for the administration — turning the system’s failures into something genuinely useful to them.
